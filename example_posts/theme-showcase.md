Welcome to **Astro Pudding**! This is a minimal, elegant and feature-rich blog theme. This post shows the extensions built into the theme to help you get started writing.

## 1. Powerful Code Blocks (Expressive Code)

The theme ships with `astro-expressive-code`, which supports syntax highlighting, code block titles, copy buttons, and line and text markers.

### 1.1 Highlighted Lines with a Title

```js title="src/utils.js" {2-4}
export function debounce(fn, delay) {
  let timer;
  return function (...args) {
    clearTimeout(timer);
    timer = setTimeout(() => fn.apply(this, args), delay);
  };
}
```

### 1.2 Text Markers

You can also mark specific text in the code:

```rust title="main.rs" "println!"
fn main() {
    println!("Hello, Pudding!");
    println!("Goodbye!");
}
```

Line numbers and collapsible sections require additional Expressive Code plugins, which the template does not enable by default.

## 3. Spoilers

With the `remark-spoiler` plugin, you can hide spoilers or sensitive content until a visitor clicks to reveal it.

You can use the simple syntax: ||this content is hidden, click to see it||.

You can also use the blacked-out form: |||this plain text is covered by default; click it or press Enter or Space to reveal it|||. Both forms are for inline plain text and are not Markdown container syntax.

## 4. Link Preview Cards

A bare URL on its own line can look plain when you cite an external reference. The theme supports link preview cards (make sure the link is on its own line):

https://github.com/huamurui/pudding

## 5. Responsive Images and Zoom (Medium Zoom)

Images in posts support lazy loading and click-to-zoom with `medium-zoom`. Remote Markdown images are output as regular images; frontmatter cover images use Astro's image pipeline. Click the image below to try zooming:

## 6. Other Typography Refinements

The theme carefully polishes spacing, fonts and responsive behavior on top of basic Markdown rendering:

- **Blockquotes**: clean and elegant, like the callout in the previous section.
- **Table of contents**: on a wide enough screen, a smoothly tracking table of contents sticks to the right side.
- **Reading progress**: a progress bar at the top of the page follows your scroll position.
- **Comments**: a Giscus-based comment section is built into the bottom of each post and can be enabled at any time.
- **Backlinks**: if other posts link to yours, a "referenced by" timeline appears automatically at the bottom!

## 7. Relative Links, Previews and Backlinks

Read the [code samples](./code-samples.md), [math examples](./math-and-katex.md#math-examples) and [Markdown extensions](./plugins-and-extensions.md). These links are relative to the current Markdown source file. At build time they get the deployment base and custom slugs resolved, and hovering them previews the published post.

Backlinks are generated by `pnpm generate` from Markdown links, and `pnpm build` runs it automatically. Previews and home page excerpts keep rich formatting but do not run post scripts.
